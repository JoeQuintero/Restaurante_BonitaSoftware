## Restaurante
### Restaurante de comida japonesa en Bonita Software.

Este proyecto fué desarrollado como un prototipo para una aplicación de un restaurante.

La aplicación contiene dos módulos: Cliente y Administrador. 

El módulo cliente sólo puede visualizar la información cargada por parte del administrador en la pantalla principal, esta información se conforma de: Mensaje de bienvenida, sugerencia del día, promoción del día y los platillos seccionados en desayuno (Estilo mexicano) y comida (Estilo japonés).

El módulo administrador puede cargar la información que será mostrada en la pantalla principal del cliente. Para acceder al cliente se hace mediante la pulsación de un botón escondido debajo de la imágen del logo en la pantalla principal, donde posteriormente se solicita un password y contraseña. Se tienen permitidos 3 intentos para iniciar sesión o el sistema se cerrará. Si el administrador accede correctamente al sistema tiene permitido registrar: Mensaje de bienvenida, platillos, sugerencias, promociones, repartidores y volver a la pantalla principal del cliente. 

El proyecto fué desarrolllado en la versión de BonitaStudioCommunnity: 2023.1 

El repositorio contiene los archivos necesarios para testear el programa por medio del archivo con extensión .bos
